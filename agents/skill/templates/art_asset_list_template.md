## 生成与回填工作流

> Producer 和用户的协作流程摘要，避免遗漏。

1. 用户复制 `art_prompts/<asset_id>.md` 中的正向/反向 prompt 到 Gemini 图像 Gem
2. 选图 / 改 prompt / 再生成，直到满意
3. 下载图片并按 `art_layout.md` 中的 Unity 落位路径保存
4. 标记本表的"✅ 已回填"列（下表）
5. 全部 🔴 优先级回填完毕后，告知 Producer 进入 Unity 开发阶段 7.4 自检
