# Project Summary
"Dungeon HR" is an engaging single-player, turn-based management and auto-battler game set in a fantasy world where players take on the role of HR managers. Players recruit and manage various monsters for battles while strategically overseeing resources. The game enhances user experience with narrative events, improved recruitment dialogues, and unique soundtracks tailored for different endings. Recent updates include a refined hero mechanism event system for dynamic interactions during battles, new class change options for monsters, and significant user interface enhancements. Players can now heal monsters during gameplay, and event cards are triggered more reliably. The project has also integrated AI technologies for code generation, music creation, and game design optimization.

# Project Module Description
The project consists of several functional modules:
- **Game Logic**: Manages game state, battle mechanics, and event triggers, including narrative explanations for monster deaths and hero mechanism events.
- **User Interface**: Displays game state, character stats, battle screens, and interaction dialogs, enhanced with new art assets and localized text.
- **Data Management**: Handles JSON-driven data for monsters, heroes, and events, including sound effects for game endings.
- **Recruitment System**: Facilitates monster recruitment for battles, featuring a refresh button for candidate selections.
- **Evaluation System**: Provides feedback on battle outcomes and manages character progression, with enhancements to dialog centering.
- **Audio Management**: Manages background music, ensuring proper transitions and stops for different game states.
- **Tutorial System**: Introduces a multi-page slide tutorial for new players, displayed on the first game start to guide them through core mechanics.
- **Save System**: Implements the ability to save and load game progress using localStorage, allowing players to resume their game from key checkpoints.
- **Restart Functionality**: Allows players to restart the game with a confirmation dialog that offers options to restart the entire game or just the current round.
- **Battle Animation System**: Newly added animations for battle phases, including attack animations, hit feedback, critical effects, and death animations for a more immersive experience.
- **Hero Mechanism Event System**: Introduces popup events during battles that present humorous options with actual gameplay effects, enhancing the game's narrative depth.
- **Healing System**: Allows players to restore a monster's health using a "heal" button, which consumes shards based on the monster's current health status.
- **AI Integration**: Utilizes AI for code generation, music composition, and game design enhancements.

# Usage
To get started with the project, follow these steps:
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Build the project:
   ```bash
   pnpm run build
   ```
3. Run linting to ensure code quality:
   ```bash
   pnpm run lint
   ```
