# Project Summary
"Dungeon HR" is an engaging single-player, turn-based management and auto-battler game set in a fantasy realm where players assume the role of an HR manager. This unique blend of resource management and storytelling allows players to recruit various monsters for battles while strategically managing their resources. Recent updates have significantly improved user experience, particularly through a revamped recruitment dialog that allows refreshing monster candidates using shards. Key features include an advanced evaluation system, level advancement mechanics that do not consume action points, and enhanced localization for better accessibility to Chinese-speaking players.

# Project Module Description
The project consists of several functional modules:
- **Game Logic**: Manages the game state, battle mechanics, and event triggers.
- **User Interface**: Displays the game state, character stats, battle screens, and interaction dialogs, now enhanced with new art assets and localized text.
- **Data Management**: Handles JSON-driven data for monsters, heroes, and events.
- **Recruitment System**: Facilitates monster recruitment for battles, featuring a refresh button for candidate selections.
- **Evaluation System**: Provides feedback on battle outcomes and manages character progression, with recent enhancements to dialog centering.

# Usage
To get started with the project, follow these steps:
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Build the project:
   ```bash
   pnpm run build
   ```
3. Run linting to ensure code quality:
   ```bash
   pnpm run lint
   ```
