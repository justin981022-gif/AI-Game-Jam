# 地下城打工人 (Dungeon HR) — 核心概念文档

> 状态：✅ 已确认（2026-04-22）
> 本文档是三人团队及各自 AI 的唯一设计基准，后续策划/美术/开发均以此为准。

---

## 一句话 Pitch

你是魔王城新上任的 HR 总监。勇者定期突袭，你需要招募怪物、管好薪酬、抵御每一波冲击，撑过 N 波让魔王城成功上市。

---

## 核心循环

```
【准备阶段】每天有限行动点，三选操作：
  ├─ 招募：从 AI 生成的简历中 3 选 1
  ├─ 扩建：增加怪物槽位
  └─ 发奖金：临时提升指定怪物本场战力

【战斗阶段】倒计时归零，勇者突袭：
  └─ 自动战斗演算 + 随机突发事件（玩家二选一，影响走势）

【绩效考评】战后处理：
  └─ 存活者升级 / 阵亡者发抚恤金 / 表现差的解雇 / 接受怪物谈薪

循环，勇者逐波变强
```

---

## 胜负条件

| | 条件 |
|--|------|
| **赢** | 撑过 N 波勇者突袭，魔王城成功上市 |
| **输①** | 某波战斗后怪物全部阵亡/离职，地牢无人值守 |
| **输②** | 灵魂碎片归零且无法支付下一日薪水，公司破产 |

---

## 战斗判定

双方血量池耗尽制：勇者队伍有总 HP，我方怪物持续输出伤害，先归零一方输。突发事件选择影响双方 HP 走势。

---

## 经济系统

| 类型 | 说明 |
|------|------|
| **薪水** | 招募时锁定（xxx 灵魂碎片/天），每日自动扣除；怪物升级后可发起谈薪，拒绝可能导致消极怠工或离职 |
| **奖金** | 战前主动发放，临时提升该怪物本场战力，战术层消耗 |
| **扩建** | 花费灵魂碎片增加怪物槽位，投资型支出 |

> 具体数值区间（薪水范围、奖金倍率、扩建成本）由策划 agent 推导。

---

## 怪物差异设计

**基础属性（简历可见）**
- ATK：每回合对勇者造成的伤害
- HP：存活时间，也是我方血量池的一部分
- 薪水/天：长期经济压力

**词条系统**
- 简历显示 1~2 个词条，另有 1 个隐藏词条入职后触发
- 词条直接映射战斗属性，例：
  - `团队毒瘤` → 同槽怪物 ATK -10%
  - `吃苦耐劳` → HP +20%
  - `易燃体质` → 遇火焰系勇者伤害翻倍
  - `社恐` → 奖金效果减半
