# 地下城打工人 (Dungeon HR) — 核心概念文档

> 状态：✅ 已确认（2026-04-22；2026-06-02 v1.1 经济五轴；2026-06-02 v1.2 恢复差异化招募成本；2026-06-03 v1.3 再次取消招募成本恢复招募免费）
> 本文档是三人团队及各自 AI 的唯一设计基准，后续策划/美术/开发均以此为准。

---

## 一句话 Pitch

你是魔王城新上任的 HR 总监。勇者定期突袭，你需要招募怪物、管好薪酬、抵御每一波冲击，撑过 N 波让魔王城成功上市。

---

## 核心循环

```
【准备阶段】每天有限行动点，三选操作：
  ├─ 招募：从 AI 生成的简历中 3 选 1
  ├─ 扩建：增加怪物槽位
  └─ 发奖金：临时提升指定怪物本场战力

【战斗阶段】倒计时归零，勇者突袭：
  └─ 自动战斗演算 + 随机突发事件（玩家二选一，影响走势）

【绩效考评】战后处理：
  └─ 存活者升级 / 阵亡者发抚恤金 / 表现差的解雇 / 接受怪物谈薪

循环，勇者逐波变强
```

## 胜负条件

| | 条件 |
|--|------|
| **赢** | 撑过 N 波勇者突袭，魔王城成功上市 |
| **输①** | 某波战斗后怪物全部阵亡/离职，地牢无人值守 |
| **输②** | 灵魂碎片归零且无法支付下一日薪水，公司破产 |

## 战斗判定

### 推进方式

- 默认每 **1.2～1.5 秒**自动推进一条战斗文字
- 玩家点击可立即跳到下一条（加速）
- 遇到突发事件节点**自动暂停**，等待玩家决策
  - 限时 **10 秒**，超时默认选择**不利选项**
  - 每场战斗最多触发 **3 个突发事件**，是否触发为随机机制（具体触发概率/条件由数值策划确定）

### 战斗实现：分段实时演算

战斗非一次性黑盒计算，以 ROUND_TICK 为单位分段推进：

> **每个 ROUND_TICK** = 双方各攻击一次 + 输出一条战斗文字 + 更新双方血条

### 战斗状态机

```
BATTLE_START → ROUND_TICK（循环）→ EVENT_TRIGGER（暂停等待决策）→ 继续 ROUND_TICK → BATTLE_END
```

### 视觉呈现

| 区域 | 内容 |
|------|------|
| **左侧** | 滚动战斗文字区，逐条显示战斗日志 |
| **右侧** | 双方 HP 条实时动画 |
| **突发事件** | 全屏卡片 + 两个选项 + 圆形倒计时进度环 |

## 经济系统

| 类型 | 说明 |
|------|------|
| **薪水** | 招募时锁定（xxx 灵魂碎片/天），每日自动扣除；**招募本身免费**，无一次性招募费；怪物升级后可发起谈薪，拒绝可能导致消极怠工或离职（v1.3 再次取消招募成本，恢复 v1.1 招募免费规则）|
| **奖金** | 战前主动发放，临时提升该怪物本场战力，战术层消耗 |
| **扩建** | 花费灵魂碎片增加怪物槽位，投资型支出 |
| **通关绩效提成**（v1.1 新增）| 每场战斗胜利后自动结算到账户，金额 = 通关保底 + 存活怪物数加成 + 输出量加成（"减员率 KPI + 业绩 KPI"双轴）；具体公式见 balance.md §2.9 |
| **AP 换碎片 / 打零工**（v1.1 新增）| 准备阶段第 4 个动作：HR 总监临时离开办公室处理外勤杂事 / 帮 CEO 跑财务流程报销，每消耗 1 行动点换得固定碎片（次优变现选项，比扔掉 AP 强但单位价值 < 自费 small bonus）；具体公式见 balance.md §2.10 |

> 具体数值区间（薪水范围、奖金倍率、扩建成本、绩效提成参数、AP 换碎片汇率）由策划 agent 推导。

## 怪物差异设计

**基础属性（简历可见）**
- ATK：每回合对勇者造成的伤害
- HP：存活时间，也是我方血量池的一部分
- 薪水/天：长期经济压力

**词条系统**
- 简历显示 1~2 个词条，另有 1 个隐藏词条入职后触发
- 词条直接映射战斗属性，例：
  - `团队毒瘤` → 同槽怪物 ATK -10%
  - `吃苦耐劳` → HP +20%
  - `易燃体质` → 遇火焰系勇者伤害翻倍
  - `社恐` → 奖金效果减半

## 修订记录

### v1.3（2026-06-03）— 再次取消招募成本，恢复招募免费规则

**根因**：v1.2 引入差异化招募成本（TANK 6 / DPS 12 / RANGE 10）经实测发现起步压力过大，反而压制了"轻量经济管理"基调。用户决策再次取消招募成本，恢复 v1.1 招募免费规则。

**修订 1 处**：

1. **§经济系统「薪水」行**：v1.2 表述"招募时支付一次性招募费（按怪物模板 6/10/12 碎片差异化）+ 锁定日薪"恢复为"招募时锁定日薪 + 招募本身免费，无一次性招募费"，与 v1.1 语义对齐。
   - 数值层联动（详见 balance v0.6.0 §0/§3.1/§4.3）：启动碎片 70 → 50（净启动资金等同：v0.5.0 70 - 招募 24 ≈ v0.6.0 50）
   - P03 触发链稳定保留：L02→L03 间 47 ≥ 45 不提前触发，L03 战后 42 < 45 触发（裕度 3 碎片，比 v1.2 裕度 1 略宽容）

**未改动**：§经济系统 其他 4 行（奖金/扩建/通关绩效提成/AP 换碎片均不变）；§待策划 Agent 推导的数值；§核心循环；§胜负条件等。

### v1.2（2026-06-02）— 取消招募免费规则，恢复差异化招募成本（已被 v1.3 推翻）

**根因**：v1.1 提出"招募免费仅锁日薪"与传统经济游戏直觉不符（怪物入职无入门成本，仅薪水扣款偏轻量）。用户拍板恢复**一次性招募费**机制，且按怪物模板差异化定价。

**修订 1 处**：

1. **§经济系统「薪水」行**：原 v1.1 表述"招募本身免费，无一次性招募费"改为"招募时**支付一次性招募费**（按怪物模板 6/10/12 碎片差异化）+ **锁定日薪**"
   - 差异化定价（详见 balance v0.3.0 §3.1）：MON_TANK 6 / MON_RANGE 10 / MON_DPS 12
   - 叙事框架：高产怪物（DPS）市场紧缺溢价 100%，老实人（TANK）薪水低市场不抢手，平衡型（RANGE）中等定价

**未改动**：§经济系统 其他 4 行（奖金/扩建/通关绩效提成/AP 换碎片均不变）；§待策划 Agent 推导的数值；§核心循环；§胜负条件等。

**v1.3 已推翻**：v1.3 再次取消差异化招募成本，本节作为历史决策记录保留。
