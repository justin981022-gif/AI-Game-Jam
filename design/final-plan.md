# 最终融合方案 — 地下城打工人（Dungeon HR）

**版本**：v1.0
**日期**：2026-04-27
**决策人**：主策划 + PD（联合签署）
**输入**：`design/drafts/zhiyu-qi/`、`design/drafts/chuwen-huang/`、`design/drafts/xiaolong-zhuo/`
**约束**：1 个月工期、3 人程序员轮换团队、H5/WebGL 2GB 上限、aiart 出图主路径

---

## 决策原则

1. **基线优先**：当前 `design/levels.md` v1.1 / `design/narrative.md` v1.2（即 zhiyu-qi 版）已经过两轮主策划 review，是已知风险最低的骨架，作为最终方案主干
2. **低成本高收益融合**：草稿之间互补的精华，**实现成本低于半天**且**情感/节奏收益明显**的项目，全部纳入
3. **严控副线**：Jam 体量（7 关，25–40 分钟）容不下双副线；任何**新增美术资产 ≥ 3 套**或**数值平衡复杂度阶跃**的提案推迟到 v2
4. **保留思路，废弃实现**：被废弃的草稿不是"判决错误"，而是"性价比不符当下窗口"——其概念以 v2 迭代项的形式留在路线图

## 二、废弃清单（不纳入 MVP，理由记录）

| # | 来源 | 内容 | 废弃理由 |

| 1 | xiaolong-zhuo | **保洁公司换皮（渊净保洁 · B 区）** | zhiyu-qi 的"魔王城 IPO + 蓝色史莱姆穿西装"美术参考已锁定，换皮意味着替换全部文案/UI/美术参考，性价比为负；魔王城叙事的高概念辨识度更利于 Jam 展示 |
| 2 | xiaolong-zhuo | **三职业体系 CL/SV/MD** | 引入意味着：美术资产 ×3（每职业差异化形象）、数值平衡复杂度阶跃（互斥技能 + 推荐阵容 + 职业位限定事件）、UI 改动（职业徽章/推荐阵容提示）。zhiyu-qi 的"随机词条"已为招募提供足够策略空间。1 个月 + 3 人程序员团队消化不了 |
| 3 | xiaolong-zhuo | **K 系列悬疑副线（K01–K04 + D04/D05/D06 + E01a/E01b）** | 副线总工作量极大：4 个 K 触发点 + 3 个相关 D 事件 + 双结局分支 + 多套新美术（PDA 邮件、抽屉闪光、便签 UI、CG 画面）。且与"上市倒计时 vs 经营压力"主线张力冲突，会稀释核心戏剧性 |
| 4 | chuwen-huang | **C02/C03/C04/C05 内心向突发事件** | C03 跨场疲劳词条持久化会增加状态机复杂度；C02/C04/C05 与 B 系列功能重叠。MVP 仅纳入 C01 作为情绪锚点，其余推迟 |
| 5 | xiaolong-zhuo | **D 系列突发事件（D01–D06）** | 派系冲突机制依赖三职业体系，三职业废弃则 D 系列基础不存在 |

**说明**：废弃项的设计文档保留在 `design/drafts/` 下作为路线图参考，不删除。

## 三、v2 迭代候选（MVP 完成后视余量启动）

4. **P3** — K 系列完整悬疑副线 + E01a/E01b 双结局：作为"内容向 DLC"，体量级新增
