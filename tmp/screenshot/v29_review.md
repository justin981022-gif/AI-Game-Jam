## 🔴 阻塞项

### Issue 1：在岗怪物槽位用错了资产（用户圈 1：左上）

**现象**：当前已招募怪物（维克塔·蘑菇怪 LV.1）的槽位卡，背景是 **A-UI-RESUME**（米色羊皮纸 + brass 顶带 + 签名线 + 印章位）。

**问题**：
- A-UI-RESUME 的视觉语义是「**应聘简历**」，按 `game_design §11.4` 仅用于「招募时翻看 3 选 1 的应聘卡片」。
- 在岗怪物槽位（`game_design §11.1` 主屏的 `[槽1][槽2]`）需要的是「工牌 / 座位卡」语义：BUST 头像 + 名字+等级 + HP 条 + 关键词条 1-2 个。
- RESUME 的 brass 顶带 + 签名线 + 印章位会挤压数值显示空间——这是用户反馈「人物的特性以及能力都不太看得清」的根因。

**修法（推荐 — 不出新图）**：
- 槽位容器改用 **CSS / Atoms 渲染**：圆角矩形 + 莫兰迪米白（`#F2EDE0` / `#E8E1D0` 二选一）+ 1px 边框（`#3D3A36` α0.5）+ 轻阴影。
- 头像槽用 **A-CHR-BUST-{角色 id}**（v1.2 已出 11 张，包括 W01-W04+ELITE 与 6 张 candidate）。
- HP 条用 **A-UI-HPBAR**（已就位）。
- 词条用文字 chip（CSS 圆角小标签）。

**槽位卡布局参考**：

```
┌────────────────────────┐
│ [BUST 头像 96×96]      │
│ 维克塔·蘑菇怪  LV.1     │
│ ▰▰▰▰▰▰▰▰▱▱  84/84    │   ← A-UI-HPBAR
│ ATK 10  CRIT 5%        │
│ ✓ 吃苦耐劳  ✓ 团队协作  │
└────────────────────────┘
```

**替代方案（不推荐，会多 1 张 aiart）**：出 `A-UI-SLOT-CARD`（256×320 透明 PNG，米色卡身 + 顶部 BUST 槽 + 中数值 + 底词条）。MVP 阶段不建议。

### Issue 2：L01 起始槽位应为 2，不是 3

**现象**：截图顶端「怪物槽位（1/3）」表示 L01 当前已招 1 人、总槽位 3。Alex v29 修复 #5「初始槽位 — L01 改为 3 个槽位」与规范不符。

**规范引用**：
- `balance.md §3.6.1`：`SLOTS 起始 = 2`，扩建到 5。
- `game_design.md §3 槽位`：起始 2。
- `game_design.md §6 L01 数据`：「3 AP 可做『招募 + 扩建 + 奖金』完整教学循环」——这套教学循环依赖「起始 2 槽 + L01 内可扩建到 3」。

**佐证**：截图中央显示「扩建（45）」按钮——45 正是规范 §2.8 的「第 4 槽」价格，证明 Alex 实现里当前是从 3 槽起步。

**影响**：
- 扩建成本曲线偏移：玩家第一次扩建付 45（应付 30）。
- L01 教学循环失效。
- 账户曲线 / P03 触发链全部基于「启动 50 碎片 + 第 3 槽 30 cost」算的（balance §3.7 / design_review v1.6）。

**修法**：
- 回退 v29 修复 #5：`怪物槽位（0/2）`，第三槽显示 `+扩建` 占位（点击触发扩建，花 30 碎片，进位到第 4 槽时变 45，第 5 槽变 60）。

### Issue 3：动作按钮排版错乱（用户圈 2：右上）

**现象**：四个准备阶段按钮（招募 / 扩建 / 发奖金 / 打零工）当前布局是 `[图标][文字][空白长方形]`，文字和数值都看不清。

**规范化布局**（建议告知 Alex）：

```
┌────────────────────────────────┐
│ [图标]  招募          1 AP     │   ← 左：图标+名称  右：成本/AP
│         无碎片消耗             │   ← 第二行副说明 12px 灰字
└────────────────────────────────┘
```

**四个按钮分别填值**：

| 按钮 | 主名 | 右栏 | 副说明 |
|------|------|------|--------|
| 招募 | 招募 | 1 AP | 免费 |
| 扩建 | 扩建 | 1 AP | 30 / 45 / 60 碎片（按当前槽数显当前价） |
| 发奖金 | 发奖金 | 1 AP | 8 / 15 / 25（三档可选） |
| 打零工 | 打零工 | 1 AP | +4 碎片 |

**字号建议**：主名 16-18px，右栏成本 14px，副说明 12px 灰字（`#3D3A36` α0.6）。
